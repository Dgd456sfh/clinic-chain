# Clinic-Chain 🏥

Clinic-Chain is a full-stack **Clinic Management System** designed to simplify patient, doctor, receptionist, and admin management in one platform.

## ✨ Features

* 🔐 Role-based authentication
* 👨‍⚕️ Doctor dashboard
* 🧑‍💼 Admin dashboard
* 🧑‍💻 Receptionist management
* 🧑‍⚕️ Patient dashboard
* 📋 Patient registration & management
* 📄 Medical PDF upload and viewing
* 🔎 Patient search
* 📊 Clinic management

## 🛠️ Tech Stack

* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend:** Next.js API Routes
* **Database:** MongoDB + Mongoose
* **Authentication:** JWT + bcrypt
* **Deployment:** Vercel

## 🚀 Run Locally

```bash
git clone https://github.com/Dgd456sfh/clinic-chain.git
cd clinic-chain
npm install
npm run dev
```

Create a `.env.local` file and add your MongoDB connection and JWT secret.

Then open:

```text
http://localhost:3000
```

## 👥 User Roles

**Admin →** Manage clinics and users
**Doctor →** Manage patients and medical information
**Receptionist →** Register and manage patients
**Patient →** View personal information and medical records

## 🎯 Goal

To provide a simple, centralized, and efficient digital platform for managing clinic operations and patient records.
